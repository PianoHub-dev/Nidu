Nidu is a free browser-based MIDI visualizer similiar to Synthesia, Embers and Seemusic.
Current Features:
- Customizable Notes, Particles, Glow, Impact, Color
- Customizable Sound Settings
- Connect and record your own MIDI
- Exporting available in 1080p 60fps
- VFX Preview Section
- Trim MIDI files

To access Nidu's premium features you need a to activate your key in the "Activate" tab.
